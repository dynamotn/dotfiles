# Aerospace
## Modifier keys
- `Super` (Command/⌘) - Main modifier for all keybindings

## Layout management

| Keybind | Action |
|---------|--------|
| `Super+,` | Cycle layouts (tiles ↔ horizontal/vertical) |
| `Super+.` | Toggle fullscreen |
| `Super+/` | Toggle floating ↔ tiling layout |
| `Super+Shift+Up`, `Super+Shift+K` | Join window with above |
| `Super+Shift+Down`, `Super+Shift+J` | Join window with below |
| `Super+Shift+Left`, `Super+Shift+H` | Join window with left |
| `Super+Shift+Right`, `Super+Shift+L` | Join window with right |

## Window focus navigation

| Keybind | Action |
|---------|--------|
| `Super+Left`, `Super+H` | Focus window to left |
| `Super+Right`, `Super+L` | Focus window to right |
| `Super+Up`, `Super+K` | Focus window above |
| `Super+Down`, `Super+J` | Focus window below |

## Window moving

| Keybind | Action |
|---------|--------|
| `Alt+Super+Left`, `Alt+Super+H` | Move window left |
| `Alt+Super+Right`, `Alt+Super+L` | Move window right |
| `Alt+Super+Up`, `Alt+Super+K` | Move window up |
| `Alt+Super+Down`, `Alt+Super+J` | Move window down |

## Window resizing

| Keybind | Action |
|---------|--------|
| `Super+Shift+-` | Resize window smaller (`resize smart -50`) |
| `Super+Shift+=` | Resize window larger (`resize smart +50`) |

## Workspace management

| Keybind | Action |
|---------|--------|
| `Super+1..9,0` | Switch to workspace `1`-`9` or `0` |
| `Super+Shift+1..9,0` | Move window to workspace `1`-`9` or `0` (focus follows) |
| `Super+Tab` | Switch to previous workspace (back-and-forth) |
| `Super+Shift+Tab` | Move workspace to next monitor (wrap around) |
| `Ctrl+Super+Left` / `Ctrl+Super+Right`, `Ctrl+Super+H` / `Ctrl+Super+L` | Move workspace to the left/right monitor (wrap around) |

## Application launching

| Keybind | Action |
|---------|--------|
| `Super+Return` | Open terminal (kitty + zellij) |
| `Super+E` | Browser, personal profile at home / enterprise profile at the office |
| `Super+Shift+E` | Browser, the other profile |
| `Super+M` | Mail client, personal profile at home / enterprise profile at the office |
| `Super+Shift+M` | Mail client, the other profile |

## Binding modes

### Main mode
- Default mode for all window management and navigation

### Service mode
Enter with `Super+;`

| Keybind | Action |
|---------|--------|
| `Esc` | Reload config and exit mode |
| `R` | Flatten workspace tree (reset layout) |
| `F` | Toggle floating/tiling layout |
| `Backspace` | Close all windows except current |

### Apps mode
Enter with `Super+Esc`

| Keybind | Action |
|---------|--------|
| `Esc` | Reload config and exit mode |
